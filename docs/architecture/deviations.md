## 已确认差异

- 中央 G2rain 目录暂无本项目对应的正式 Profile 或登记项，当前使用本地基线。
- 根 `pom.xml` 与 2026-09-06 的构建均为 `1.0.4`；工作区现有、未提交的 `README.md` 将版本改为 `1.0.2`，提交前需确定预期版本。

## 待补验证

- 覆盖嵌套分页作用域、异常路径、`PagingEscape`、无 count、空结果及不安全排序输入。
- 对复杂 SQL（联合、分组、去重、子查询）验证 count SQL 正确性。
- 对 SQL AST 缓存在并发、序列化失败和缓存淘汰场景下进行验证。
